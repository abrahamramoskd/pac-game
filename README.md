# 🟡 Pac-Man en Python

Recreación del clásico arcade en un **solo archivo Python** usando `pygame`.
Sin imágenes externas — todos los sprites se dibujan con primitivas geométricas.

## ✨ Características

- Laberinto completo de 21×23 celdas con túneles laterales
- 4 fantasmas con IA individual (Blinky, Pinky, Inky, Clyde)
- Modo asustado con parpadeo al finalizar + fantasmas comibles
- Energizadores pulsantes y fruta bonus
- Sistema de niveles: velocidad progresiva en cada oleada
- Animación de boca de Pac-Man y animación de muerte
- HUD con hi-score, puntaje, nivel y vidas
- Código comentado línea a línea con fines didácticos

## 🚀 Instalación

```bash
pip install pygame
python pacman.py
```

## 🕹️ Controles

| Tecla   | Acción              |
|---------|---------------------|
| `← ↑ → ↓` | Mover Pac-Man    |
| `P`     | Pausar / reanudar   |
| `R`     | Reiniciar partida   |
| `ESC`   | Salir               |
